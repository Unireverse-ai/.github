# Contributing and reporting issues

Thank you for helping make UniReverseAI's public reference material easier to inspect and reproduce.

## Report a reference bug

Open an Issue in the affected repository. Include:

- The code or document revision and your operating system/runtime version.
- The command or minimal steps you ran.
- A synthetic input that reproduces the problem.
- Expected behaviour, actual behaviour and the relevant error output.
- Which documented assumption or control may be affected.

Remove credentials, personal information and customer/system details from reports. Replace them with invented values that preserve the failure. A public Issue is not a suitable channel for private due-diligence documents.

## Ask a documentation question

Link to the relevant page and section. Explain what is ambiguous, the decision you are trying to make and a proposed correction if you have one. Keep questions about the reference separate from claims about a customer's environment or business results.

## Propose a change

For a substantial change, describe the problem and proposed scope in an Issue before preparing a large patch. Keep a pull request focused and include meaningful validation where behaviour changes. Mark synthetic examples clearly and update affected assumptions, execution instructions and limitations.

Submit only material that you are entitled to share. Public visibility does not change the repository's rights or grant an open-source licence; refer to its rights statement when considering reuse.

## Report a sensitive issue privately

For a suspected vulnerability, exposed credential or data-disclosure issue, contact [Eric@unireverseai.com](mailto:Eric@unireverseai.com) with the repository, affected revision and a minimal description. Do not publish working secrets or customer data in an Issue or pull request. A coordinated next step can then be agreed through the private channel.

For commercial support, project information or private verification, contact [Eric@unireverseai.com](mailto:Eric@unireverseai.com). Public Issue activity does not establish a support contract or response commitment.
